⚙️ ENGINE SLOT — INSTALL PANEL

This is the integration point. Configure one object and the Lab goes live for everyone. The engine just needs to accept a 2D image and hand back a printable .glb model URL.


        

          How to install the engine (for the crew with credentials)
          
Open catalog/index.html, find the block labeled TOMMY_3D_ENGINE at the top of the script, and fill in your engine's endpoint. Contract: POST { image: <dataURL>, prompt: <text> } → { modelUrl: "https://…/model.glb" }. The Lab already renders any returned GLB in the viewer and falls back gracefully when the slot is empty.
