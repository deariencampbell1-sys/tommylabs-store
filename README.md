# TOMMY LABS - 3D Printed Creations Shop

Your complete website: 4 products (Batman, Dragon, Wolf, Tiger), each with a real
photo AND a click-to-open 3D model, plus the scroll-spinning 3D owl centerpiece.

## What's in this folder
- index.html                 - the entire website (one page, all features built in)
- img/                       - all product & showcase photos
- models/                    - the 5 real 3D models (.glb)
- vendor/model-viewer.min.js - the 3D viewer engine (local copy, no internet needed)
- carrd/                     - adaptation kit for Carrd.co (CSS + embed snippets + steps)
- Start-Tommy-Labs.bat       - double-click to preview locally (Windows)

## Go live in 30 seconds
1. Unzip this file into a folder
2. Go to https://app.netlify.com/drop
3. Drag the folder onto the page
DONE. Free HTTPS URL, 3D included.

Other free hosts that work the same way: Neocities.org, GitHub Pages, Cloudflare Pages.

## Why there's no .html upload for Carrd
Carrd.co is a visual builder, not a file host. See carrd/carrd-steps.md for the
exact way to recreate the site inside Carrd (or just use Option A - 30 seconds).

## Preview locally
- Double-click Start-Tommy-Labs.bat (starts a tiny server + opens your browser)
- The 3D models need the server (browsers block 3D from plain file://) - that's
  why the shortcut exists instead of double-clicking index.html.
